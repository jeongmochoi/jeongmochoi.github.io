# Jeong-Mo Choi (최정모)

부산대학교 화학과 최정모 부교수의 개인 학술 홈페이지 소스 저장소입니다.
연구와 논문, 저서·번역서, 강의, 대중 강연 및 미디어 활동을 소개합니다.
통계역학, 분자모델링, 계산화학을 이용해 생명 시스템의 분자 원리를 연구합니다.

Source repository for the personal academic website of Jeong-Mo Choi, Associate Professor of Chemistry at Pusan National University.
The site presents his research, publications, books, teaching, and public outreach.

## 관리 원칙

- 변경은 최신 `main`에서 분리한 브랜치에서 작업하고, 변경 내용과 검증 결과를 담은 Draft PR로 검토합니다.
- 변경 범위에 맞게 서식·링크를 검사하고, 사이트 변경 시에는 Jekyll 빌드와 관련 검사를 수행합니다. 홈페이지 소유자의 명시적 승인 후에만 병합·배포합니다.
- 별도 변경 요청이 없는 한 기존 디자인, 국문·영문 구조와 URL, 검색엔진 및 강의 PDF 정책을 유지합니다.

상세 기준: [홈페이지 관리·배포 절차](docs/SITE_MAINTENANCE.md), [검색 노출·PDF 정책](docs/SEARCH_VISIBILITY.md), [에이전트 작업 지침](AGENTS.md).
